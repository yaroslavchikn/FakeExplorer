# Fake Explorer

Полноценная копия проводника Windows, которая выглядит и работает как оригинал, но все операции производятся в изолированной папке `FakeSystem` в домашней директории пользователя.

## Особенности

- Полная копия интерфейса проводника Windows
- Все стандартные операции: создание, удаление, переименование, свойства
- Двойной клик для открытия папок и просмотра файлов
- Адресная строка для навигации
- Панель инструментов с навигацией
- Контекстное меню
- Строка состояния
- Два режима просмотра: таблица и список
- Сортировка по колонкам

## Важно

Это приложение является "пустышкой" - все операции происходят в изолированной папке `~/FakeSystem` и НЕ влияют на реальную систему.
